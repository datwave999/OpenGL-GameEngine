# OpenGL-GameEngine

> **Note:** This is a temporary README.

A custom 3D Game Engine built from scratch using OpenGL and C++.

## Overview

This project is currently under active development. The goal is to build a high-performance, Data-Oriented Design (DOD) based Entity Component System (ECS) architecture for a flexible and robust game engine.

## Features (Work in Progress)
- Custom OpenGL rendering pipeline
- Entity Component System (ECS) Architecture
- Data-Oriented Design (DOD) principles
