# Graphics Pipeline

- current renderer = forward rendering (lighting is calculated when drawing each object's fragments)
- scene geometry comes from AssetManager; RenderSystem gets the objects to draw from ECS
- Application clears the default framebuffer, visible states draw into it, then the window swaps buffers
- full application update/render order is explained in [1.Architecture](1.Architecture.md#current-frame-order)

## CPU Data -> GPU Data

- geometry:
    - StandardMeshes / Assimp -> Vertex + index vectors -> AssetManager -> VBO/EBO + VAO
- per-object transform:
    - TransformComponent -> TransformSystem -> cached matrices -> RenderCommand -> shader uniforms
- camera:
    - Camera -> CameraMatrices -> UBO binding 0
- lighting:
    - light components + transforms -> LightSystem -> LightUBO -> UBO binding 1
- material:
    - AssetManager.CreateMaterial -> material UBO -> RenderSystem binds it to binding 2
    - diffuse/specular textures -> texture units 1 and 2 -> sampler uniforms
- indexed draw:
    - bound VAO + shader + textures/UBOs -> glDrawElements -> vertex shader -> rasterization -> fragment shader -> depth/blend operations -> framebuffer
- [IMP] UBO binding points and texture units are separate (material UBO binding 2 doesn't mean texture unit 2)

## Mesh Data / Vertex Attributes

- VBO (Vertex Buffer Object): stores vertices in GPU memory
- EBO (Element Buffer Object): stores indices, used to select vertices for each triangle
- VAO (Vertex Array Object): stores how to read vertex attributes and which EBO to use
- AssetManager uploads vertices/indices using GL_STATIC_DRAW
- current vertex layout (from Vertex in AssetData.h):

| Location | Field | Values | Shader input |
|---|---|---|---|
| 0 | Position | 3 floats | aPos |
| 1 | Normal | 3 floats | aNormal |
| 2 | TexCoords | 2 floats | aTexCoords |

- stride = sizeof(Vertex), offsets are calculated using offsetof [don't assume GLM fields have no padding]
- CPU vectors can be released after uploading; AssetManager keeps the GPU buffers/VAOs alive
- geometry generation and importing are explained in [3.Resources](3.Resources.md)

## RenderSystem: Extraction -> Sorting -> Execution

- **Owns**:
    - renderQueue: vector of RenderCommands, cleared and reused each render
- **RenderCommand**:
    - shaderHandle, materialHandle, meshHandle
    - copies of modelMatrix and normalMatrix
- **Extraction**:
    - gets entities with RenderComponent + TransformComponent
    - uses modelHandle to get the ModelAsset [skips invalid model handles]
    - creates one command for each node, using its mesh/material and the entity's cached matrices
    - shader handle comes from that node's material
- **Sorting**:
    - sorts by shaderHandle, then materialHandle
    - puts draws using the same shader/material together to reduce repeated binds
    - mesh isn't part of the sort key
- **Execution**:
    - tracks current shader, material and mesh handles (reset for each Render call)
    - when shader changes: enables it and sets cameraPos
    - sends model and normalMatrix uniforms for every command
    - when material changes: binds diffuse/specular textures, sets sampler units and binds material UBO
    - when mesh changes: binds its VAO
    - calls glDrawElements(GL_TRIANGLES, indexCount, GL_UNSIGNED_INT, 0)
    - unbinds VAO at the end [shader, texture and UBO bindings remain]
- last draw argument 0 = byte offset into the bound EBO; indexCount is the number of indices
- [IMP] referenced materials, shaders, meshes and textures are assumed valid (only model lookup is checked)
- one entity can produce multiple draws, one per model node
- sorting reduces state changes, doesn't combine draw calls [no instancing or frustum culling currently]

## Camera Data

- **Owner**: Camera (unique_ptr(Buffer)), created as GL_DYNAMIC_DRAW
- **Binding**: UBO binding 0, GLSL block CameraData
- **Layout**:
    - projection (mat4)
    - view (mat4)
- UpdateUBO packs both matrices into CameraMatrices, then replaces the buffer's contents
- view = glm::lookAt(Position, Position + Front, Up)
- projection = glm::perspective(FOV in radians, width / height, 0.1f, 100.0f)
- projection is recalculated using the dimensions currently stored by Window
- core and unlit vertex shaders use this block; overlay doesn't use it
- [IMP] projection comes before view in both C++ and GLSL
- minimized windows can have height 0; the current projection code doesn't guard this

## Light Data

- **Owner**: LightSystem (unique_ptr(Buffer)), created as GL_DYNAMIC_DRAW
- **Binding**: UBO binding 1, GLSL block LightData
- **Layout**:
    - directionalLight
    - pointLights[MAX_POINT_LIGHTS] (16)
    - spotLights[MAX_SPOT_LIGHTS] (8)
    - numPointLights, numSpotLights and two padding floats
- component color * each intensity -> ambient/diffuse/specular colors in upload structs
- radius -> attenuation coefficients:
    - constant = 1
    - linear = 4.5 / radius
    - quadratic = 75 / (radius * radius)
- spotlight inner/outer angles (degrees) -> cosine cutoffs
- LightSystem uploads the full block every update; active counts tell the shader how many array entries to read
- closest lights are selected using squared camera distance + partial_sort
- radius controls fading, it isn't a hard cutoff or a visibility test
- ECS light position/direction rules are explained in [ECS Guide](4.ECS_Guide.md#lightsystem)

## Material Data / Texture Units

- **Owner**: AssetManager owns each material's Buffer and textures
- **Binding**: material UBO binding 2, GLSL block MaterialData
- **Layout** (16 bytes):
    - matShininess (float)
    - matSpecularIntens (float)
    - matPad1, matPad2 (two floats)
- material UBO is created using GL_STATIC_DRAW; RenderSystem switches the binding when material changes
- **Textures**:
    - diffuse texture bound to texture unit 1
    - specular texture bound to texture unit 2
    - sampler uniform stores the unit number, not the texture id
    - glActiveTexture(GL_TEXTURE0 + unit) selects the unit before glBindTexture
- diffuse texture provides surface color and output alpha
- specular texture's red channel controls highlight strength, multiplied by matSpecularIntens
- matShininess controls how tight the highlight is
- [IMP] editing MaterialAsset's CPU floats alone wouldn't update its already-created UBO

## std140 Layout

- uniform blocks use layout(std140, binding = ...) in GLSL
- C++ upload data must match the GLSL order, offsets and array strides
- current light structs use vec3 + float fields to fill 16-byte slots
    - DirectionalLightComponent / GLSL DirectionalLight: four slots
    - PointLightUBOData / GLSL PointLight: four slots
    - SpotLightUBOData / GLSL SpotLight: five slots
- active counts + trailing padding fill the final 16-byte slot in LightUBO
- camera mat4 values each occupy four 16-byte columns
- [IMP] changing fields, light limits or GLM alignment settings needs a layout check on both sides
- padding is for memory layout, it doesn't affect the lighting calculation

## Vertex Shader: Model -> World -> View -> Clip

- **core.vert**:
    - reads position, normal and UV attributes
    - model * vec4(aPos, 1.0) -> world position
    - projection * view * model * vec4(aPos, 1.0) -> gl_Position (clip space)
    - normalMatrix * aNormal -> world-space normal
    - passes world position, transformed normal and UVs to the fragment shader
- TransformSystem calculates model = translate * rotate * scale
    - with column vectors, scale is applied first, then rotation, then translation
- normalMatrix = transpose(inverse(mat3(model)))
    - keeps normals correct with non-uniform scale
    - fragment shader normalizes the interpolated normal again
- openGL clips triangles, divides by clip-space w and maps them into the viewport
- rasterization generates fragments and interpolates the outputs for the fragment shader
- [IMP] lighting calculations use world space (light positions, normals, FragPos and cameraPos must agree)

## Fragment Shader: Blinn-Phong Lighting

- **core.frag**:
    - normalizes Normal and calculates viewDir = normalize(cameraPos - FragPos)
    - samples diffuse texture once for albedo/alpha and specular texture once for its red channel
    - calculates directional light, then adds each active point/spot light
    - outputs vec4(total lighting, diffuse texture alpha)
- **Common Terms**:
    - ambient = light ambient color * albedo
    - diffuse factor = max(dot(normal, lightDir), 0)
    - halfwayDir = normalize(lightDir + viewDir)
    - specular factor = pow(max(dot(normal, halfwayDir), 0), max(matShininess, 0.0001))
    - specular = light specular color * material intensity * specular map value * specular factor
- **Directional Light**:
    - lightDir = -light.direction, same direction across the scene
    - no distance attenuation
    - [IMP] current shader doesn't normalize this direction, pass a normalized direction for consistent lighting
- **Point Light**:
    - light vector = light.position - FragPos
    - normalizes that vector using its length
    - attenuation = 1 / (constant + linear * distance + quadratic * distance squared)
    - multiplies ambient, diffuse and specular by attenuation
- **Spot Light**:
    - uses the same distance fading as point lights
    - theta = dot(lightDir, -light.direction)
    - intensity = clamp((theta - outerCutOff) / (innerCutOff - outerCutOff), 0, 1)
    - multiplies diffuse/specular by intensity for soft cone edges
    - ambient still uses attenuation outside the cone [isn't multiplied by cone intensity]
- use positive radius and inner angle < outer angle for a valid spotlight fade
- shader doesn't guard zero distance at the exact position of a point/spot light

## Unlit Shader

- **unlit.vert**:
    - uses model + CameraData to transform positions
    - passes UVs to the fragment shader
- **unlit.frag**:
    - returns the diffuse texture sample directly
    - doesn't calculate lighting or use the light/material UBOs
- used for visible light markers and the flashlight model in the current scene
- an unlit model doesn't give off light by itself [needs a light component too]
- RenderSystem uses the same submission path, so it also tries to set uniforms unused by unlit
    - Shader caches location -1 and prints a warning on the first lookup

## Depth Testing / Framebuffer

- Application enables GL_DEPTH_TEST during initialization
- clears color and depth buffers before rendering visible states
- scene draws use the default depth comparison (GL_LESS) and write depth
- depth test keeps farther fragments from drawing over nearer surfaces
- scene blending is disabled; fragment alpha alone doesn't make scene objects transparent
- rendering goes straight to the default framebuffer [no offscreen framebuffer or post-processing pass]
- after all states render: Input.EndFrame, then swapBuffers
- [IMP] shader/material sorting doesn't provide the back-to-front ordering needed for transparent scene objects

## Pause Overlay

- PauseState draws directly, bypassing the ECS render queue
- **Before Drawing**:
    - enables GL_BLEND
    - glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)
    - disables GL_DEPTH_TEST so the overlay covers the 3D scene
- **Shaders / Mesh**:
    - fullscreen quad from StandardMeshes.CreateOverlay
    - overlay.vert uses positions directly in clip space [no camera/model matrices]
    - overlay.frag outputs black with alpha 0.6
    - blending leaves 40% of the scene color under the black overlay
- **Draw**:
    - enables overlay shader and binds its VAO
    - calls glDrawElements, then unbinds VAO and disables the shader
- **After Drawing**:
    - enables depth testing and disables blending
    - restores the state expected by current scene rendering [doesn't save every previous openGL setting]
- PlayState keeps rendering while paused, using its last updated camera/light/transform data

## Graphics Abstraction

### Buffer class

Used to create buffers (VBO, EBO, UBO) easily
- Holds buffer id and type
- for VBO and EBO:
	- Bind and Unbind buffers (For configuring the Mesh's VAO)
- for UBO:
	- Bind buffer base to a specific location (Global)
- updateData (For Dynamic buffer like UBO):
	- Maps the requested range for writing, invalidating the full buffer or only that range [allows openGL to discard the old data, doesn't guarantee no stalls]
- Constructor generates buffer and adds data
- Destructor deletes the buffer
- updateData copies into mapped memory and unmaps it; if mapping fails, the current implementation skips the copy without logging

### VertexArray class

Used to configure how openGL reads a mesh's vertex and index buffers

- **Owns** (Private variables):
	- vaoID: id of the Vertex Array Object (VAO)
- **Working**:
	- Constructor:
		- generates and binds the VAO
	- addVertexBuffer:
		- checks that the Buffer passed in is a VBO (GL_ARRAY_BUFFER)
		- binds the VAO and VBO
		- sets the attribute location, number of values, type, stride and offset using glVertexAttribPointer
		- enables that attribute
		- AssetManager uses location 0 for position, 1 for normal and 2 for texture coordinates
	- setIndexBuffer:
		- checks that the Buffer passed in is an EBO (GL_ELEMENT_ARRAY_BUFFER)
		- binds the EBO while this VAO is bound (EBO binding is stored in the VAO)
	- Bind and Unbind: select this VAO or bind VAO 0
	- getID: used to store the VAO id in MeshGPU
	- Destructor: deletes the VAO
- [IMP] VAO stores how to read the buffers, doesn't own or copy their vertex data (AssetManager keeps the VBO and EBO alive)

### Shader class

Used to load, compile and link shader files into an openGL program

- **Owns** (Private variables):
	- shaderID: id of the linked shader program
	- uniformLocationCache: array storing locations of uniforms [avoids repeated glGetUniformLocation calls]
- **Working / Life Cycle**:
	- Constructor (takes vertex, fragment and optional geometry shader file paths):
		- compiles vertex and fragment shaders using compileShader
		- creates a program and attaches these shaders
		- compiles and attaches geometry shader if a path is provided
		- links the program and prints any linking error
		- deletes the individual shader objects (the linked program is kept)
		- fills uniformLocationCache with -2 [location hasn't been checked yet]
	- loadShaderSource:
		- reads the file into a string, prints an error if file couldn't be opened
	- compileShader:
		- loads source, creates shader object and compiles it
		- prints compilation errors
	- enableShader / disableShader:
		- glUseProgram(shaderID) / glUseProgram(0)
	- setUniform:
		- overloaded for bool, int, float, vec3, mat3 and mat4
		- gets the uniform location from the cache and calls the matching glUniform function
		- [IMP] shader must be enabled before setting its uniforms
	- Destructor: deletes the shader program
- compilation/linking errors are printed, but currently don't stop asset creation

### Uniform enum and Location Cache

- Uniform enum names the uniforms that can be set through Shader's setUniform functions
- includes model, view, projection, normalMatrix, materialDiffuse, materialSpecular and cameraPos
- UniformNames array in Shader.cpp maps these enum values to the names in GLSL
- GetUniformLocation:
	- uses the enum value as an index into uniformLocationCache
	- if value is -2: asks openGL for the location and stores it
	- if location is -1: prints a warning (uniform doesn't exist or was optimized out)
	- later calls reuse the stored location, including -1
- [IMP] enum and UniformNames must stay in the same order (static_assert checks their counts match)
- view and projection are currently sent through the camera UBO, even though their enum entries still exist
